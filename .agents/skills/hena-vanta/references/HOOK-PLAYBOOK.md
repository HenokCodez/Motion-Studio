# Hook playbook (first 3–15 seconds)

The hook decides whether the viewer stays. The reference video opens with a new, different object EVERY ~2 seconds and never
leaves a word on screen for long. Reproduce that density in the hook only; the body can breathe a little more.

## Rules for the hook
1. **Cold open, no logo, no intro card, no chapter card.** Frame 0 already shows the first word/object.
2. **A visual event every <= 1.5 s for the first 8 s** (a word counts; a new object counts double). After 8 s every <= 2.5 s.
3. **Use only these (strongest) animations in the hook:** A03 stat pill, A06 bubble strike, A07 reply bubble, A02 word stack, A05 word swap, A04 beam, A55 number drops to zero, A57 myth vs truth, A60 search-bar question, A39 Venn, A54 before/after, A14 proof screenshot (real), A18 gradient word, A48 trap warning.
4. **The first object must carry the title's promise** (a number, a question, a claim). Never open on a generic player card unless the topic is the platform itself.
5. **Each hook scene supports the spoken idea** (see IDEA-TO-ANIMATION). If the sentence is not a number/claim/question, use A02/A05.
6. **Payoff is NOT shown in the hook** (Hena Vanta formula: payoff near the end). Show the tension only: the number, the claim, the contradiction.
7. **No SFX, no music.** Retention comes from motion density + curiosity, not sound.
8. **Real proof early**: one captured screenshot (A14/A45) by second 8–12 if the title promises a result.
9. Hook scenes are <= 2.5 s each, blur hand-off 6 f overlap, drift on.

## Recipes (copy the one that matches the title type; adjust durations to the spoken words)

### H1 — Experiment ("I tried X for N days… is it worth it?")
| t | scene | animation |
|---|---|---|
| 0.0–1.6 | the headline number said first ("360 days") | A03 stat pill (count-up), `blue` |
| 1.6–3.4 | the expectation as a claim | A06 bubble ("it'll be easy" typed word by word, no strike yet) |
| 3.4–5.0 | the reality line | A06 strike-through on the claim + A05 word swap "it wasn't" (red keyword) |
| 5.0–7.0 | the question | A60 search bar types the video's question |
| 7.0–9.5 | proof the experiment is real | A14 real screenshot in window, slow zoom |
| 9.5–12 | what we'll answer | A08 list cards (3 items max, one per cue) — or A05 words |
### H2 — Money/result ("How much did I make?")
A55 (number drops/climbs) -> A58 meter views vs money -> A57 myth/truth -> A14 earnings proof (REAL only) -> A05 words.
### H3 — Investigation / truth ("The truth about clipping")
A57 myth vs truth (card with strike) -> A07 reply bubble "WHAT" style objection -> A39 Venn (what really decides) -> A14 proof -> A48 trap warning.
### H4 — Tutorial ("How to start clipping")
A02 word stack ("three things you need") -> A56 checklist ticks as items are named -> A10 folder row (steps) -> A11 window (first step).
### H5 — Explanation ("how YouTube decides who sees your video")
A01 player card (topic = the platform) -> A04 beam ("who sees it") -> A33 channel->thumbs (catalogue) -> A29 spike+badge (the outlier) -> A39 Venn.
### H6 — Shorts (< 45 s; vertical)
0–1 s A55/A03 number | 1–3 s A06 claim | 3–6 s A57 flip | 6–12 s A14 proof (phone mock A15) | 12 s+ A05 words with one red keyword per 3 s. Loop-friendly last frame = first object.

## Pacing check before moving on
* Count visual events in 0–15 s. Long-form target >= 9, Shorts target >= 7 in 0–10 s.
* Count distinct animation IDs in the hook: >= 5 (long-form), >= 4 (Shorts).
* No text-only scene longer than 2.5 s. No FootageNote in the first 8 s.
