# Idea -> animation (the rule that keeps every animation meaningful)

Find the voiceover sentence's job in the left column. Use only the IDs listed. If none fits, use A05 (plain word swap). Write the chosen ID and the "why" in PLAN.md.

| The narration is… | Use | Why it helps |
|---|---|---|
| a big number (views, $, days, proposals) | A03, A25 (percentage), A55 (falls to 0), A63 (time) | the number itself is the object |
| a claim the narrator will challenge | A06 (strike-through bubble), A57 (myth/truth flip) | negation is visible |
| the audience's reaction/objection | A07 | conversation metaphor |
| a definition ("X is…") | A27 | sentence inside an object, bold-italic term |
| a short question the viewer is asking | A60 | the question typed like a real search |
| a comparison of two things | A59, A54, A41, A49 | side-by-side makes difference obvious |
| a ratio/intersection ("X + Y = Z") | A39 | overlap = result |
| views ≠ money, one quantity vs another | A58, A35 | bar lengths show the gap |
| a funnel (100 -> 12 -> 2) | A62 | narrowing shows loss |
| time passing/effort | A61 (calendar), A63 (stopwatch), A53 (journey) | time becomes visible |
| the story over time (journey) | A53 | ONE persistent timeline, one event per scene |
| steps in order | A10/A26 (folders), A56 (ticks), A34 (S-curve) | order is visible |
| a parallel list of 3–5 items | A08 (+A09 focus) | one item per cue |
| a small fix list with notes | A46 | one line at a time |
| a real example (video/post/product) | A20, A21, A36, A40–A42 | show the real thing, highlight the lesson word |
| proof (dashboard/page/analytics) | A14, A37, A45, A50 | real screenshot, push-in toward the part discussed |
| two proof states (before/after) | A49 | |
| attention / what viewers notice | A04 | beam = focus |
| a mistake most beginners make | A48 (trap) after A47 (calm line) | warning has weight |
| a transformation/upgrade | A18, A24 -> A25 | word/tile changes |
| a tool/price/CTA | A30, A31 | pill press |
| a creator/outlier spot | A32, A33, A29, A13 | zoom along the object |
| an honest source/credit | A43, A45 footnote | transparency |
| a chapter change | A64 | the only ding |
| a story character beat (feeling) | A44 | relatable moment |
| a quote | A15, A47 | |
| just narration with no object | A02 or A05 or A47 | keep it light, <= 20% runtime |
| missing footage | A52 | 20 px note, nothing else |

Never use: A19 (notification) for a real event; A17 (menu) without a copy/paste/delete idea; A10/A26 (folders) when there aren't discrete steps; A39 when there are not exactly two ingredients; A29 without a computed multiplier; A55 without a real number.
