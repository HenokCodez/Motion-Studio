# asset-protocol.md
1. Channel brand: assets/brand/vanta-brief-logo.png (cream V on dark circle, lime slider dot; do NOT recolor). Used by A27 (intro/outro), A29 (subscribe CTA), optional small corner mark that never covers content.
2. Company/product logos (already fetched for DeepSeek, ChatGPT/OpenAI, Claude, Gemini, Grok/xAI, Mistral, Meta in assets/logos/ from SVGL via raw.githubusercontent.com because official press pages were not reachable; provenance.json has URL+date; grok.svg was recolored to #231F20 from the white dark-mode variant. Re-fetch from official brand pages when network allows): for every named company/model/product fetch the current official logo: official brand/press page -> Wikimedia Commons -> svgl.app -> simpleicons.org. Command: `python3 scripts/asset-fetch.py logo <name> <url>` -> assets/logos/<name>.<ext> + provenance.json (URL, date). No invented logos. Groups ("other closed-tier models") -> A28 with the real logos: ChatGPT/OpenAI, Claude/Anthropic, Gemini/Google, Grok/xAI (+ others named). Every named entity gets its real logo at least once; DeepSeek appears in varied animations (A27, A28 highlight, A21).
3. Screenshots: `python3 scripts/asset-fetch.py screenshot <name> <page-url>` (Playwright) -> assets/screenshots/<name>.png, shown with A30 (pass src="<name>.png"). Official pages only.
4. Photos of people/hardware: official/press sources only; save under assets/photos/ and pass the filename to A35 (photos[]), A48 (src) or A49 (photos[]). Without a file those draw a labelled silhouette placeholder; never use stock images as stand-ins.
5. NEVER search for or generate GIFs. Leave named slots (GIF_SLOT_01...) in the plan notes for the user.
6. Network blocked or file missing: append to assets/MISSING.md (the script does this), keep the labelled placeholder (A28/A30 draw one automatically), tell the user which files to drop in. Never fake a logo.
7. Voiceover goes in assets/audio/ and is referenced by plan.audio ("audio/voiceover.mp3").
