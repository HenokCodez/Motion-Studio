## 1. Key Editorial & Factual Corrections Applied

Following the pre-approval audit, all factual claims, pricing structures, and long-running compositions have been rigorously corrected:

1. **Official Pricing Validation**:
   - **Adobe Single Apps (Premiere Pro / Photoshop)**:
     - Monthly billed monthly: **$34.49 / month** ($413.88 / year).
     - Annual commitment billed monthly: **$22.99 / month** ($275.88 / year).
     - Annual prepaid: **$263.88 / year**.
   - **Adobe Creative Cloud All Apps**:
     - Monthly billed monthly: **$89.99 / month** ($1,079.88 / year).
     - Annual commitment billed monthly: **$59.99 / month** ($719.88 / year).
   - **Microsoft 365**:
     - Microsoft 365 Personal: **$6.99 / month** or **$69.99 / year**.
   - *On-Screen Implementation*: Scene 06 explicitly states: **"Annual Commitment, Billed Monthly"** ($22.99/mo for Premiere, $22.99/mo for Photoshop, $6.99/mo for Microsoft 365) to prevent conflating monthly no-commit and annual prepay rates.
2. **Concept vs. Benchmark Clarity ("The 90% Rule")**:
   - The script's line *"if an open-source alternative does 90% of what you need"* is an **illustrative decision-making threshold**, not a laboratory benchmark.
   - Scene 09 explicitly labels the visual as: **"Illustrative User Workflow Coverage: Core 90% Daily Tools vs 10% Proprietary Plugins"**. No fabricated benchmark tests or fake percentage scores are presented.
3. **Local AI vs. Hosted Service Precision**:
   - **Kokoro-82M**: Accurately presented as a true **local open-weight** text-to-speech model (82 million parameters, Apache 2.0 license) executing entirely offline on CPU/GPU with <1GB VRAM footprint.
   - **Krea AI**: Explicitly demonstrated as a **hosted real-time canvas web interface** (powered by cloud diffusion pipelines), while explaining that equivalent open diffusion weights (e.g. SDXL Turbo / Flux Schnell) execute locally on 6GB–12GB VRAM consumer GPUs.
4. **Decomposition of Long-Running Compositions**:
   - **Previous 35.7s Scene 15**: Split into **4 focused, organically developing scenes** (Scenes 15A, 15B, 15C, 15D, each 6.4s–10.9s), each actively demonstrating a separate business pillar (Cloud Hosting -> Enterprise Tiers -> Consulting -> Foundation Sponsorship).
   - **Previous 25.8s Scene 18**: Split into **2 distinct macroeconomic movements**: Scene 18A (Value migration down the stack to silicon, 14.1s) and Scene 18B (The subscription defensibility crisis, 11.7s).
5. **Grounded Opening ($0 Software Licenses)**:
   - Scene 01 clearly establishes that what costs $0 is **software licenses / subscriptions**, not the physical computer or electricity. The status stamp reads: **"$0 SOFTWARE LICENSES / NO RECURRING SUBSCRIPTION"**.
